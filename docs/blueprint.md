# **App Name**: Versioned Tech Docs

## Core Features:

- AWS Cognito Integration: Authentication and role management via AWS Cognito (Admin, Editor, Reader) with JWT token validation. Roles are defined in Cognito Groups.
- Document Upload via Presigned URLs: Securely upload documents to S3 using presigned URLs generated by Lambda functions.
- Document Listing and Filtering: List documents with details (name, author, date, type, size) and filtering by name, type, date, and author.
- Version History: Show document version history in a table format, enabling download of any version via presigned URLs and allowing uploads of new versions.
- Document Preview: Provide document preview functionality: PDF (iframe), Image ( img ), TXT/MD (render plain text or markdown), with a “Download to view” message for DOCX files.
- Role-Based Access Control: Control UI element visibility based on user roles (Admin, Editor, Reader) to manage permissions.
- Error Handling and Notifications: Implement global error handling and user notifications for success/error events.

## Style Guidelines:

- Primary color: Soft blue (#90AFC5) to suggest professionalism, clarity, and trust. This is well-suited for technical documentation.
- Background color: Light gray (#F0F4F8), offering a neutral backdrop.
- Accent color: Teal (#2A9D8F) to create a high-contrast element, drawing users' attention to calls to action and interactive components. This gives off the air of technical proficiency, since many programmers favor teal!
- Body and headline font: 'Inter' sans-serif for a neutral, modern style, suitable for UI and body text.
- Consistent and clear icons to represent document types, actions, and status.
- Clean and responsive layout, optimized for readability and usability across different devices.
- Subtle animations for transitions and loading states to improve user experience.
